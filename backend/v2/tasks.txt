### Task 2.2: Create Parse Resume Task (V2)
- [ ] Create `backend/app/tasks/v2/parse_resume_task.py`
- [ ] Import v1 ResumeParser class
- [ ] Create Celery task `parse_resume_task`:
  - Input: `upload_id: str, file_path: str, user_email: str`
  - Steps:
    1. Update status to "parsing"
    2. Load file using file_storage_service
    3. Call v1 ResumeParser.read_pdf()
    4. Call v1 ResumeParser.extract_resume_data() (with retry logic)
    5. Call v1 ResumeParser.save_to_mongodb()
    6. Update upload record: status="parsed", resume_id=resume_id
    7. Trigger embedding task (call existing endpoint or queue task)
    8. Update parse_task_id in upload record
  - Error handling:
    - On failure: Update status="parsing_failed", store error_message
    - Retry on: Network errors, rate limits, timeouts
    - Don't retry on: Invalid PDF, parsing errors
- [ ] Add retry decorator from celery_config_v2
- [ ] Add logging for each step

**Dependencies:** Task 1.2, Task 1.3, Task 1.4, Task 2.1
**Reuses:** `backend/app/services/resume_parser.py` (v1)

---

### Task 2.3: Create Embedding Task Wrapper (V2)
- [ ] Create `backend/app/tasks/v2/precompute_embedding_task_v2.py`
- [ ] Create Celery task `precompute_embedding_task_v2`:
  - Input: `user_email: str, upload_id: str`
  - Steps:
    1. Update status to "embedding"
    2. Call existing worker endpoint `/precompute-embedding` (or queue existing task)
    3. Poll task status until complete
    4. On success: Update status="embedding_completed"

    6. On failure: Update status="embedding_failed", store error
